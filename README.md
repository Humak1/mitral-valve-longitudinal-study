# mitral-valve-longitudinal-study

Predictive Modelling of Mitral Valve Improvement

Longitudinal mixed-effects logistic regression on 1,000 mitral valve surgery patients, comparing a standard logistic regression against a mixed-effects model with a patient-level random intercept.

Written in R and R Markdown.

The problem

Mitral valve disease often requires surgery, and outcomes vary between patients. Two surgical approaches are used in this dataset: a minimally invasive ("Mini") procedure and the conventional method. Each of the 1,000 patients was assessed twice, at baseline and at 12 months post-surgery, and the outcome recorded is binary: did mitral valve function improve, yes or no.

Because each patient contributes two observations, the measurements are not independent. Treating them as independent risks biased estimates and a misleading picture of how well the outcome can be predicted.

Four questions:

Does mitral valve function improve from baseline to 12 months?
Does improvement differ between Mini and Conventional surgery?
Is a mixed-effects model actually needed, or would standard logistic regression do?
How accurately can improvement be predicted from Surgery, Time, Gender and Smoking status?

Approach

Preparation. Reshaped wide to long so each row is one patient-time observation, coded the outcome as a 0/1 binary variable, set all predictors as factors with Baseline as the reference level for Time.

Models.

Baseline: standard logistic regression (GLM), which assumes observations are independent.
Main model: mixed-effects logistic regression (GLMM) with a random intercept for patient ID, modelling within-patient correlation directly.

Both were fitted with and without a Surgery x Time interaction.

Model selection. Likelihood ratio tests and AIC. The interaction did not significantly improve fit (chi-squared = 2.25, p = 0.134; AIC 2777.25 vs 2777.50), so the simpler main-effects model was selected.

Validation. A patient-level 70/30 train-test split, so that both observations from any given patient land in the same split. Splitting by row would leak information about a patient from training into test and inflate apparent performance.

Performance measured with ROC/AUC for discrimination, Brier score for probabilistic accuracy, and confusion-matrix metrics at a 0.5 threshold. Threshold tuning was run across a grid from 0.05 to 0.95.

Results
Metric	GLMM	GLM
AUC	~0.51	~0.51
Brier score	~0.25	~0.25
Sensitivity at 0.5	0	0

Random-intercept variance: 0.106 (SD ~0.326).

Answering the four questions:

Improvement over time: no clear evidence. The Time effect is small and not statistically significant.
Difference by surgery: no clear evidence. Odds ratios close to one.
Is the mixed model needed: yes, for valid inference. The random-intercept variance of 0.106 shows real between-patient heterogeneity that a standard GLM ignores.
Prediction accuracy: weak. AUC near 0.51 is close to random.
What the results mean

This is a negative result, and the more interesting part of the project is establishing why.

At the default threshold both models predicted "no improvement" for every test patient, because predicted probabilities all sat below 0.5. Threshold tuning raised F1 at low cut-offs, but only by predicting almost everyone as improved, which collapsed specificity. That is an artefact of the threshold, not a real gain.

Three diagnostics point to the same conclusion:

Learning curves across increasing training sizes showed training and test error staying high and close together, with no meaningful improvement as data was added. That is high bias, or underfitting.
100 repeated random splits showed test error fluctuating but never trending down, indicating sampling variance from patient heterogeneity rather than overfitting to one split.
GLM and GLMM performed almost identically, so the limitation is not the choice of model structure.

The conclusion is that Surgery, Time, Gender and Smoking status simply do not carry enough signal to predict this outcome. The mixed-effects model is still the correct choice for inference, but no modelling decision can recover information the features do not contain.

Limitations and future work

The main limitation is the feature set. Useful additions would be age, disease severity, comorbidities, or continuous clinical measurements rather than a binary outcome.

Two time points is also the minimum for a longitudinal design. More follow-up points would allow individual recovery trajectories to be modelled properly, which would open up random-slope models or joint longitudinal-survival models.

External validation on an independent dataset would be the next step for assessing generalisability.
